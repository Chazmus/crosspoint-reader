How to Install:

  1. Connect your CrossPoint device to your computer with a high-quality USB-C data cable.
  2. Power on / wake the device.
  3. Click Connect & Install Firmware above.
  4. In the browser prompt, choose the serial device (e.g. USB JTAG/serial debug unit or CP210x / /dev/ttyACM0).
  5. Confirm installation in the dialog. The flasher will program the flash and reboot your device automatically!

Flashing Guide & Troubleshooting

Helpful tips, drivers, and recovery procedures

🔌 1. Device Connection & Drivers

  • Linux: Ensure your Linux user account has permissions to access serial ports: sudo usermod -aG dialout $USER (or group uucp on Arch Linux). Log out and log back in.
  • Windows: Modern ESP32-S3 boards (X4Pro, Sticky) use the native USB-JTAG/CDC interface, which does not require external drivers. If you have an ESP32-C3 device with CP2102 or CH340 chip, install the respective USB-to-UART driver if the port doesn't appear.
  • macOS: Native USB serial is supported out of the box on macOS 10.15+.
  • USB Cable: Many USB-C cables are charge-only. Verify that your cable supports data transfer.

⚠️ 2. USB-Locked Devices (Xteink Factory Lock)

Some Xteink units purchased from third-party resellers (such as AliExpress) ship with USB flashing disabled from the factory. If the browser's serial device picker doesn't display any new device when plugging it in, you can unlock it using the official OTA unlock tool:

Open Xteink OTA Unlocker →

🔄 3. Forcing Bootloader Mode (Recovery)

If your device is unresponsive, in a bootloop, or won't accept flashing:

  1. Unplug the USB-C cable and turn off the device.
  2. Hold down the Back button (or hardware Boot button if equipped).
  3. While holding the button, plug the USB-C cable into your computer.
  4. Release the button after 2 seconds. The chip will now be in ROM Download Mode and ready to flash.

💻 4. Command-Line Flashing (Alternative)

If you prefer using esptool.py via terminal:

# Install esptool
pip install esptool

# Flash X4Pro (ESP32-S3)
esptool.py --chip esp32s3 -p /dev/ttyACM0 -b 921600 write_flash 0x10000 firmware-x4pro.bin

# Flash X3 / X4 (ESP32-C3)
esptool.py --chip esp32c3 -p /dev/ttyACM0 -b 921600 write_flash 0x10000 firmware-default.bin
